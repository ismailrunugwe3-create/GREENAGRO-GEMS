GEMS V1.4.4 SERVER-ROUTED DIRECT FORMS

IMPORTANT: Do not open index.html with content:// or file:// for full-form UAT.
1. On a computer with Python, run START_GEMS.bat (Windows) or python server.py.
2. Open http://127.0.0.1:8765 on that computer.
3. For phone UAT on the same Wi-Fi, open http://COMPUTER-LAN-IP:8765 on the phone.

This build serves each approved form as its own HTTP document route. No srcdoc/Blob/base64/document.write rendering is used.
